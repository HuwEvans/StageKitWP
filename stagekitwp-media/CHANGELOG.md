# StageKit WP Media Changelog

## Version 1.0.1 — 2026-09-07

### Added

- Accessible image lightbox with previous/next controls, keyboard navigation, overlay close, and focus restoration.
- Back to Galleries navigation on single-gallery views.

### Fixed

- Gallery grids now preserve the configured desktop column count and reduce responsively to three, two, and one columns at narrower widths.
