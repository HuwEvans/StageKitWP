
Welcome to the StageKitWP repository.  Here you will find the documentation to the ecosystem that is specifically designed to assist web builders with creating content and pages related to theatre companies.

The ecosystem consists of the: 

**StageKitWP Core Plugin:** which adds the main CPTs to extend Wordpress to Support theatre comapnay management,  The CPTs are designed to simplify how data is captured, and provide a consist method of display this data accross the website.

**StageKitWP Theme:**  Provide an integrated theme that ustilizes data from the Core CPT to Generate a comprehensive Home page for marketing of performances.  It also adds a light/dark theme switcher options that can be used.

**StageKitWP Blocks plugin:**  This will add some StageKitWP specific blocks.  They will be designed specifically to be used in conjunction with the Dark/Light Mode switcher.

**StageKitWP Import-Export Plugin:**  This plugin is used to import and export the components of the stagekitwp Theatre Manager ecosystem so that it can be reused on other sites, or so that it simplifies moving to a new site.  It can also import new data in bulk to reduce setup times for new sites.

**StageKitWP Search Optimization Plugin:**  This simplifies the tasks of adding SEO to pages.  It will automatically update the appropriate sections on a page.

**StageKitWP Members Plugin (in development):** This adds member management functions to the website. 

**StageKitWP Reading Circle Library Plugin (in development):**  This plugin is to help manage a library of scripts, and to create a voting mechanism for determining the best script(s) in a group.  The primary purpose for this plugin to help groups with a reading committee and play selection process.  Scripts can be housed electronically, or in a physical library.

**StageKitWP Sync Library Plugin (in development):**  This plugin will manage syncing data from external sources to the CPTs in the ecosystems.

**StageKitWP Media Links Plugin (road map):**  This plugin will allow connecting external media sites to present media (photos, videos) in the site

**StageKitWP Payments Plugin (road map):**  This plugin will manage processing payments for the memberships
 
**** Please Note
Repository of the old theatre-manager ecosystem.  It has been renamed StageKitWP in order to reduce possible collisions with other WordpressPlugins
